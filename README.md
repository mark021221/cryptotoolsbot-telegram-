# CryptoTools — Telegram Mini App

Монитор бирж и P2P KZT внутри Telegram: кнопка у бота открывает приложение.

## Из чего это состоит

- `webapp/` — страницы приложения (вкладки «Монитор» и «P2P KZT»).
- `server.py` — сервер: отдаёт страницы, пересылает запросы к биржам (иначе браузер Telegram их не пропустит)
  и хранит историю маржи и подписки на уведомления.
- `bot.py` + `p2p.py` — бот: открывает приложение по `/start` и **в фоне** следит за P2P-связками,
  пишет историю и шлёт уведомления.

Серверу и боту нужно работать **постоянно и в интернете**, а не на твоём компьютере.

---

## Что умеет вкладка P2P KZT

- Лучшая связка на твою сумму + сравнение цены покупки с биржевым курсом (USD/KZT × цена монеты).
- Реальные комиссии сети: выбираешь сеть (TRC20, BEP20, …) — комиссия подставляется в расчёт. Значения ориентировочные.
- Надёжность продавцов: число сделок, процент завершённых, статус мерчанта (если биржа отдаёт эти данные).
- Избранные связки (★), поиск по продавцу, компактный режим, «потянуть вниз — обновить», кнопка «скопировать» связку.
- Журнал сделок: отмечаешь выполненные сделки, видишь итоговую прибыль (хранится на твоём устройстве).
- История маржи: график с сервера (если бот запущен) или локальный.
- Уведомления: баннер и вибро, пока приложение открыто; **сообщения в Telegram, даже когда оно закрыто** (нужен запущенный бот).

## Шаг 1. Токен бота

1. В Telegram открой **@BotFather** → `/newbot`, задай имя и короткое имя (оканчивается на `bot`).
2. Сохрани токен вида `123456789:AA...`. **Никому не показывай и не светись им на скриншотах.**

## Шаг 2. Придумай секрет

`BOT_SECRET` — любая длинная случайная строка (например, 30–40 символов). Он нужен, чтобы только твой бот
мог писать историю и читать список подписчиков. Один и тот же секрет задаётся и серверу, и боту.

## Шаг 3. Сервер на Render

1. Залей папку `telegram-bot` на GitHub (Add file → Upload files).
2. На [render.com](https://render.com): **New → Web Service**, подключи репозиторий.
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python server.py`
3. Во вкладке **Environment** добавь переменную `BOT_SECRET` = твой секрет.
4. После деплоя получишь адрес вида `https://cryptotools-xxxx.onrender.com` — это `WEBAPP_URL`.
   Открой его в браузере: должна открыться страница с вкладками.

> Бесплатный план Render «засыпает» без запросов и просыпается ~30 секунд. Диск на нём может очищаться при
> пересборке — тогда накопленная история и подписки сбросятся (подписки нужно будет включить заново в настройках).

## Шаг 4. Бот на Render (чтобы работал всегда)

1. **New → Background Worker**, тот же репозиторий.
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python bot.py`
2. Во вкладке **Environment** добавь:
   - `BOT_TOKEN` — токен из шага 1
   - `WEBAPP_URL` — адрес сервера из шага 3 (с `https://`)
   - `BOT_SECRET` — тот же секрет, что у сервера
   - `POLL_SECONDS` — по желанию (по умолчанию 180)

Без запущенного бота приложение работает, но **уведомления в Telegram не приходят и история с сервера не копится**.

### Запуск на своём компьютере (для проверки)

Нужен Python **3.10–3.13** (на новейших предварительных версиях Python не устанавливаются зависимости).
Скопируй `.env.example` в `.env`, впиши значения и выполни:
```
py -3.12 -m pip install -r requirements.txt
py -3.12 bot.py
```

## Шаг 5. Кнопка в меню (один раз)

**@BotFather** → `/mybots` → бот → **Bot Settings → Menu Button → Configure Menu Button** → вставь `WEBAPP_URL`.

## Как включить уведомления

1. Напиши своему боту `/start` (без этого он не может писать тебе первым).
2. Открой приложение → вкладка P2P KZT → ⚙ → включи **«Уведомления в Telegram»**, задай порог в %.
3. Бот будет проверять связки на выбранную монету и сумму и присылать сообщение, когда они выгоднее порога
   (не чаще раза в 30 минут, если связка не стала заметно лучше).

Изменил монету, сумму или комиссию в настройках — подписка обновится сама.

## Если что-то не работает

- **Белый экран / не открывается** — `WEBAPP_URL` должен начинаться с `https://` и открываться в обычном браузере.
- **Курсы не грузятся** — сервер на бесплатном плане мог «заснуть», подожди ~30 секунд и обнови.
- **Уведомления не приходят** — проверь: бот запущен (Background Worker в статусе Live), `BOT_SECRET` одинаковый
  у сервера и бота, ты нажимал `/start` в чате с ботом, приложение открыто именно из Telegram.
- **История пустая** — серверная история ведётся для сумм 50 тыс. / 100 тыс. / 300 тыс. / 500 тыс. / 1 млн ₸
  и появляется через несколько минут после запуска бота.
- **Не у всех продавцов видна надёжность** — биржи отдают эти поля по-разному, где данных нет, бейдж скрыт.
