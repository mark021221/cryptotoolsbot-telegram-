# CryptoTools — Telegram Mini App

Папка превращает те же два инструмента (монитор бирж и P2P KZT) в Telegram-бота
с кнопкой, которая открывает приложение прямо внутри Telegram.

## Из чего это состоит

- `webapp/` — те же страницы, что были в десктоп-версии, адаптированные под Telegram
  (подстраиваются под тему Telegram, кнопка «Назад», вкладки сверху).
- `server.py` — маленький сервер: отдаёт эти страницы и пересылает запросы к биржам
  (без него браузер Telegram не пропустит запросы к Binance/Bybit/OKX напрямую).
- `bot.py` — сам бот: по команде `/start` присылает кнопку, которая открывает Mini App.

Это не `.exe`-программа — боту и серверу нужно работать **постоянно и в интернете**,
а не на твоём компьютере. Поэтому сервер придётся куда-то «задеплоить» (разместить) —
ниже самый простой бесплатный способ.

---

## Шаг 1. Получить токен бота

1. Открой в Telegram **@BotFather**.
2. Отправь `/newbot`, придумай имя и короткое имя (должно заканчиваться на `bot`).
3. BotFather пришлёт токен вида `123456789:AA...`. Сохрани его — он понадобится позже.

## Шаг 2. Разместить сервер в интернете

Самый простой бесплатный вариант — **Render.com** (можно и Railway, суть та же).

1. Зарегистрируйся на [render.com](https://render.com).
2. Залей эту папку (`telegram-bot`) к себе на GitHub (создай репозиторий и загрузи файлы —
   можно просто перетащить их на github.com через «Add file → Upload files»).
3. В Render нажми **New → Web Service**, подключи этот репозиторий.
4. Настройки сборки:
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python server.py`
   - Остальное можно оставить по умолчанию (план Free подойдёт).
5. После деплоя Render даст адрес вида `https://cryptotools-xxxx.onrender.com`.
   Это и есть твой `WEBAPP_URL` — публичный адрес твоего мини-приложения.
6. Открой этот адрес в браузере и убедись, что страница открывается и выглядит как надо.

> Бесплатный план Render «засыпает» без запросов и просыпается ~30 секунд при первом
> открытии. Для личного использования это не критично, но учитывай это.

## Шаг 3. Запустить бота

Бота держать в интернете так строго не обязательно — он может работать и на твоём
компьютере, пока ты им пользуешься. Но если нужен постоянный бот, его тоже
проще всего развернуть на Render тем же способом (ещё один Web Service или
Background Worker с Start Command `python bot.py`).

### Запуск на своём компьютере

1. Установи Python 3.10+ с [python.org](https://python.org) (отметь Add to PATH).
2. Скопируй `.env.example` в `.env` и впиши туда:
   ```
   BOT_TOKEN=токен_из_шага_1
   WEBAPP_URL=https://cryptotools-xxxx.onrender.com/
   ```
3. Открой терминал в этой папке и выполни:
   ```
   pip install -r requirements.txt
   python bot.py
   ```
4. В консоли не будет ошибок, если всё верно — бот запущен и слушает сообщения.
5. Напиши своему боту в Telegram `/start` — должна прийти кнопка «Открыть CryptoTools».

## Шаг 4. Разрешить Mini App у BotFather (один раз)

1. Напиши **@BotFather** → `/mybots` → выбери своего бота.
2. **Bot Settings → Menu Button → Configure Menu Button**.
3. Введи тот же `WEBAPP_URL` и любое название кнопки, например «Открыть».
4. Это добавит кнопку приложения ещё и в меню рядом с полем ввода — удобно, не только
   через `/start`.

## Если что-то не работает

- **Кнопка не открывается / белый экран** — проверь, что `WEBAPP_URL` начинается с
  `https://` (не `http://`) и открывается в обычном браузере без ошибок.
- **Цены на бирже не грузятся** — зайди на `WEBAPP_URL` в браузере, открой консоль
  разработчика (F12) и посмотри на ошибки в запросах к `/fwd`. Обычно это значит, что
  сервер ещё не проснулся (бесплатный Render) — подожди и обнови страницу.
- **Бот не отвечает на `/start`** — проверь, что процесс `python bot.py` не завершился
  с ошибкой, и что `BOT_TOKEN` скопирован без лишних пробелов.
- Если ошибки Render/Railway непонятны — пришли мне текст ошибки, разберёмся.

## Отличия от десктоп-версии

- Настроек меньше: масштаб и цвета подстраиваются под тему Telegram автоматически,
  отдельного экрана настроек нет (Mini App обычно открывают на телефоне, там это не нужно).
- Один экран с вкладками сверху вместо бокового меню — такой вид привычнее в Telegram.
- Логика расчёта P2P-связок и список бирж — такие же, как в десктоп-версии.
